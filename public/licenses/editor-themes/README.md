# Встроенные темы редактора

Пять палитр поставляются вместе с приложением. Данные находятся в src/assets/editor-themes.json и включаются в сборку интерфейса. При выборе встроенной темы приложение использует локальные данные.

Палитры получены из официальных пакетов VS Code с помощью существующих импорта и адаптации Yade. Из пакетов использованы только данные оформления; исходные программы расширений не выполнялись и не включены в приложение. Цвета отдельных категорий могут отличаться от VS Code из-за различий синтаксических разборщиков.

| Встроенная тема | Исходный пакет | Версия | Лицензия |
| --- | --- | --- | --- |
| One Dark Pro | [zhuangtongfa.Material-theme](https://marketplace.visualstudio.com/items?itemName=zhuangtongfa.Material-theme) | 3.20.6 | [MIT](onedark-LICENSE.txt) |
| Dracula Theme | [dracula-theme.theme-dracula](https://marketplace.visualstudio.com/items?itemName=dracula-theme.theme-dracula) | 2.25.1 | [MIT](dracula-LICENSE.txt) |
| Catppuccin Mocha | [Catppuccin.catppuccin-vsc](https://marketplace.visualstudio.com/items?itemName=Catppuccin.catppuccin-vsc) | 3.19.0 | [MIT](catppuccin-LICENSE.txt) |
| GitHub Dark Default | [GitHub.github-vscode-theme](https://marketplace.visualstudio.com/items?itemName=GitHub.github-vscode-theme) | 6.3.5 | [MIT](github-LICENSE.txt) |
| GitHub Light Default | [GitHub.github-vscode-theme](https://marketplace.visualstudio.com/items?itemName=GitHub.github-vscode-theme) | 6.3.5 | [MIT](github-LICENSE.txt) |

Оригинальные уведомления об авторских правах сохранены в файлах лицензий этого каталога и копируются в поставку приложения.
