# Иконки файлов

Локальная выборка SVG из [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme/tree/ced21b9b5241c1efa502a8c46ec7363a690a7058/icons), версия исходников `ced21b9b5241c1efa502a8c46ec7363a690a7058`.

[Лицензия MIT](../licenses/Material-Icon-Theme-LICENSE.txt) включена в приложение. Для JSX и TSX интерфейс добавляет обозначения JS и TS: исходные иконки отличаются только цветом.
