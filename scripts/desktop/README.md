# Сборка приложения для macOS

Нужны официальный Node.js **26.8.1**, npm, Rust **1.90+** с Cargo в `PATH` и Xcode Command Line Tools. Оба сценария устанавливают зависимости через `npm ci` и работают независимо от текущего каталога терминала. Сборка создаётся для архитектуры текущего Mac.

## Собрать и установить локально

```sh
./scripts/desktop/install.command
```

Сценарий собирает и проверяет `.app`, затем устанавливает её в `/Applications`. Для обновления используется та же команда. Перед заменой нужно полностью завершить Yade через **Cmd+Q**. Прежняя `.app` сохраняется до успешной замены; данные приложения и проекты не изменяются. Новая версия автоматически не запускается.

Если `/Applications` недоступна для записи, можно установить приложение в личную папку:

```sh
./scripts/desktop/install.command "$HOME/Applications"
```

При обновлении указывайте ту же папку, чтобы заменить установленную копию.

## Собрать для передачи другим

```sh
./scripts/desktop/distribute.command
```

Сценарий создаёт `.dmg` в `src-tauri/target/release/bundle/dmg/` и сохраняет `.app` в `src-tauri/target/release/bundle/macos/` для проверки содержимого. Получатель открывает образ и переносит Yade в «Программы». Node.js входит в приложение; Git, Codex и Claude Code устанавливаются отдельно.

Оба файла `.command` также можно запускать двойным нажатием в Finder, если нужные инструменты доступны в `PATH` открытого терминала.

Сейчас используется подпись ad-hoc, без Developer ID и нотариального заверения Apple: macOS получателя может потребовать разрешить открытие приложения в системных настройках. Поддерживается macOS **13.5+**. Правила резервного копирования и возврата старой версии описаны в [инструкции поставки](../../docs/desktop-delivery.md).

## Проверка сценариев

```sh
node --test scripts/desktop/scripts.test.mjs
```

Проверка подменяет команды сборки и работает во временной папке, не затрагивая установленное приложение.
