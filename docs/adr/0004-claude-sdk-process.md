# Подключать Claude Code через отдельный процесс с официальным SDK

Для полноценного чата выбран вспомогательный процесс на TypeScript с официальным Claude Agent SDK, который управляет установленным пользователем неизменённым Claude Code. Это добавляет среду Node.js к приложению с ядром на Rust, но позволяет использовать API SDK для сессий, событий и разрешений вместо собственной реализации управляющего протокола CLI.

Среда Node.js и вспомогательный процесс поставляются внутри готового приложения; пользователь отдельно устанавливает и обновляет Claude Code. Совместимость версий и соответствие конкретной схемы обязательному сценарию с личной подпиской пока не подтверждены.

Основания: [обзор SDK](https://code.claude.com/docs/en/agent-sdk/overview), [TypeScript SDK](https://code.claude.com/docs/en/agent-sdk/typescript).
