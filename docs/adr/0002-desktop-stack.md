# Использовать Tauri 2, Rust, React с TypeScript и SQLite

Первую версию выпускаем для macOS с возможностью последующей поддержки других ОС. Для приложения выбраны Tauri 2, локальное ядро на Rust, интерфейс на React с TypeScript и SQLite для локального состояния: быстрый запуск, отзывчивость и потребление памяти важнее короткого срока разработки.

Tauri использует системный WebView вместо поставки собственного браузерного движка, что уменьшает состав дистрибутива, но требует учитывать различия платформ. По уточнённому решению пользователя отдельные замеры производительности и нагрузочный прототип не планируются. Быстрый отклик и умеренное потребление памяти остаются качественными требованиями к реализации; измеренные показатели не заявляются.

Основание: [модель процессов Tauri](https://v2.tauri.app/concept/process-model/).
