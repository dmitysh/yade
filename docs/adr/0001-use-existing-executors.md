# Подключать готовых исполнителей

В MVP ADE подключаем Claude Code и Codex вместо реализации собственного цикла взаимодействия с моделями и инструментами. Это позволяет сосредоточить собственную реализацию на рабочей среде и управлении задачами, но делает возможности общения, разрешений и продолжения сессий зависимыми от поддерживаемых интерфейсов исполнителей. Обязательный сценарий — личные подписки пользователей; подключение через API-ключи в ADE не реализуется. Для Codex используется app-server с текущим штатным входом установленного CLI, для Claude — отдельный процесс с официальным SDK и штатным входом неизменённого Claude Code. Совместимость выбранных интеграций с подписками ещё необходимо подтвердить.
