# Навигация по коду

Yade сохраняет CodeMirror и использует готовый `@codemirror/lsp-client`. Анализ Go выполняет `gopls`, TypeScript/JavaScript, включая TSX/JSX, — `typescript-language-server` с TypeScript. Сервер Go запускается при открытии файла или поиске символов. Для TypeScript и JavaScript в новом пространстве нажмите «Подключить навигацию» и подтвердите доверие к его коду. Доверие относится к пространству и его пути, действует до выхода из Yade и применяется также к запуску разговора Claude. Подсветка и редактирование доступны до подтверждения и во время подключения.

## Подготовка

Установленные инструменты обнаруживаются автоматически. Для `gopls` дополнительно проверяется `~/go/bin`. Если поддержки нет, над редактором появляется «Установить поддержку языка». Установка выполняется по нажатию в подкаталог `languages` каталога данных Yade и требует сети. Глобальные пакеты и файлы проекта не меняются.

Для установки `gopls` 0.22.0 требуется Go 1.26 или новее; автоматическая загрузка новой версии Go отключена. Для TypeScript/JavaScript нужны Node.js 22.22.2 или новее и npm; устанавливаются `typescript-language-server` 6.1.0 и TypeScript 6. Сам Go и Node.js приложение не устанавливает. Ошибку установки или подключения можно исправить и повторить проверку.

## Управление на macOS

| Действие | Сочетание |
| --- | --- |
| Файлы и символы в одном окне | Двойной `Shift` |
| Файл по имени или пути | `⇧⌘O` |
| Символ в рабочей копии | `⌥⌘O` |
| Структура текущего файла | `⌘F12` |
| К объявлению или использованиям | `⌘B` или `⌘` + щелчок |
| Определение типа | `⇧⌘B` или `⇧⌘` + щелчок |
| Реализация | `⌥⌘B` или `⌥⌘` + щелчок |
| Использования | `⌥F7` или `⌥⌘F7` |
| Строка или строка:столбец | `⌘L` |
| Назад / вперёд по коду | `⌘[` / `⌘]` |
| Переименование символа | `⇧F6` |
| Подсказка аргументов | `⌘P` |
| Поиск текста по рабочей копии | `⇧⌘F` |

Те же действия доступны через меню «Команды навигации». `⌘B` и `⌘` + щелчок на использовании ведут к объявлению; на самом объявлении находят использования, исключая объявление из результатов. Единственное использование открывается сразу, несколько — списком. Компактное окно рядом с символом показывает имя символа, файл, номер строки и фрагмент кода; стрелки выбирают результат, `Enter` открывает его, `Escape` или щелчок снаружи закрывает окно. Для первых 100 результатов загружаются фрагменты кода, у открытых файлов учитываются несохранённые правки. Состав использований определяет языковой сервер: TypeScript, например, может включать ссылки в импортах.

В поиске работают сокращения имени, стрелки, `Enter` и `Escape`. Недавние файлы идут первыми, текст запроса сохраняется при переключении вкладок поиска. При нескольких определениях или реализациях открывается список для выбора. Переходы открывают обычные вкладки и сохраняют место возврата. История переходов хранится до закрытия приложения.

## Референс GoLand

За основу взяты встроенная раскладка установленного GoLand 2025.2.1 и [справка по основной навигации](https://www.jetbrains.com/help/go/navigating-through-the-source-code.html). В раскладке `⌘B` и `⌘` + щелчок привязаны к одной команде `GotoDeclaration`; для переходов назад и вперёд используются `⌘[` и `⌘]`. Сочетания также описаны в [раскладке macOS](https://www.jetbrains.com/help/go/reference-keymap-mac-default.html).

| Элемент GoLand | Применение в Yade |
| --- | --- |
| Переход от использования к объявлению и обратно к использованиям | Общая команда для клавиатуры, мыши и меню; одна цель открывается сразу, несколько предлагаются на выбор |
| [Быстрый список использований](https://resources.jetbrains.com/help/img/idea/2025.2/go_show_usages_in_separate_window.png) | Компактное окно у символа с файлом, строкой и кодом; видимый редактор сохраняет контекст |
| [Общий поиск](https://resources.jetbrains.com/help/img/idea/2025.2/go_search_all_window.png) | Единое окно с вкладками, недавними файлами и сохранением запроса при смене вкладки |
| [Структура файла](https://www.jetbrains.com/help/go/navigating-through-the-source-code.html) | Поиск по символам текущего файла и переход по `Enter` |

Цвета, шрифты, иконки и оформление окон берутся из существующего интерфейса Yade.

Поиск файлов и текста учитывает `.gitignore`; `.git` и символические ссылки не обходятся. Для текста доступны регистр, целое слово, регулярное выражение и маски файлов через запятую, например `*.go, *.ts`. При достижении ограничения 200 совпадений интерфейс предлагает уточнить запрос. Переход по результату учитывает несохранённый черновик и сообщает, если найденный текст уже изменён.

## Зависимости и диагностика

Стандартная библиотека и внешние зависимости, возвращённые языковым сервером, открываются во вкладках только для чтения. Ранее открытые ссылки сохраняются для своей рабочей копии, поэтому вкладки зависимостей восстанавливаются после перезапуска. Прямое чтение произвольного внешнего пути не разрешается; внутренние проверки путей и защита `.git` сохраняются.

Подсказки типов появляются при наведении. Ошибки и предупреждения языкового сервера отмечаются в редакторе; кнопка «Проблемы» открывает общий список с переходами. Список отражает полученные сообщения сервера и не заменяет полную проверку проекта сборкой или линтером.

## Переименование

После ввода нового имени сначала показываются затронутые файлы и сравнение текущего текста с результатом. Несохранённые ручные правки входят в исходную версию. Автосохранение приостановлено на время диалога и возобновляется после его закрытия.

«Применить переименование» повторно проверяет версии файлов и черновиков. Изменения ограничены текущей рабочей копией; внешние зависимости и операции переименования самих файлов отклоняются. Перед записью подготавливаются новые и резервные версии, сохраняются права доступа. При ошибке записи приложение пытается вернуть уже записанные файлы; если внешнее изменение мешает возврату, сообщает о сохранённых черновиках и путях резервных копий. Открытые редакторы обновляются вместе с файлами.

## Проверка

Обычные проверки: `npm test`, `npm run build`, `cargo test --manifest-path src-tauri/Cargo.toml`. Для тестов управления процессами macOS требуется запуск вне песочницы.

Интеграционная проверка использует настоящие языковые серверы и подменяет только связь представления с настольным ядром. Она создаёт временные проекты, проверяет переходы, символы, подсказки, автодополнение, диагностику, переименование нескольких файлов с ручной правкой и чтение стандартной библиотеки Go. Серверы и временные файлы удаляются после проверки. Пути к исполняемым файлам задаются окружением:

```sh
env YADE_LANGUAGE_INTEGRATION=1 YADE_GOPLS=/path/to/gopls YADE_TYPESCRIPT_SERVER=/path/to/typescript-language-server npx vitest run src/CodeNavigation.integration.test.tsx
```
