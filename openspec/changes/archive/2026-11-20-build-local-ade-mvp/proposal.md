# Proposal

## Why

Пользователю и его команде нужна локальная среда разработки, которая объединяет Claude Code и Codex с проектами, рабочими пространствами, кодом, терминалом и Git. Первый выпуск должен предоставлять законченный повседневный сценарий по модели Orca, сохраняя отзывчивость интерфейса и умеренное потребление памяти.

## What Changes

- Создать самостоятельное настольное приложение для macOS на Tauri 2, Rust, React, TypeScript и SQLite с возможностью дальнейшего переноса на другие ОС.
- Добавить локальные проекты и группы, Git worktree и пространства общей папки, подготовку, архивирование и безопасное удаление пространств.
- Подключить установленные Claude Code и Codex через штатный вход пользователей по личным подпискам; реализовать потоковый чат, разрешения, остановку и явное продолжение.
- Разрешить несколько параллельных сессий в одном пространстве с общими файлами и видимой активностью. Пользователь самостоятельно координирует правки; независимая работа выполняется в отдельных worktree.
- Включить редактор, поиск, просмотр изменений, интерактивный терминал и Git с подготовкой отдельных фрагментов изменений.
- Сохранять историю, черновики и расположение вкладок; продолжать задачи после закрытия окна и предупреждать перед полным выходом.
- Поставлять готовое приложение со встроенным Node.js; обновлять его вручную с сохранением локальных данных.

Редактор дополнен навигацией по символам, автодополнением, подсказками типов, диагностикой и переименованием для Go и TypeScript/JavaScript через готовые языковые серверы. Управление следует сочетаниям JetBrains, оформление сохраняет стиль приложения.

За пределами MVP: встроенный браузер, отладчик, собственное автоматическое распределение задач, редактор настроек навыков и MCP, вход через API-ключи и автоматическое обновление. Численные нормативы производительности и отдельные замеры не вводятся.

## Capabilities

### New Capabilities

- `project-management`: открытие локальных проектов, объединение в группы и переключение контекста.
- `workspace-management`: пространства репозитория и папки, создание от исходной точки, подготовка, архивирование и удаление.
- `executor-sessions`: разговоры с Claude Code и Codex, параллельное выполнение, события, разрешения и продолжение.
- `code-editor`: дерево файлов, вкладки, поиск, ручное редактирование, сохранение и защита черновиков.
- `integrated-terminal`: интерактивные оболочки внутри пространств и управление их процессами.
- `git-workflow`: ветки, состояние, сравнение, индексирование файлов и фрагментов, коммиты, отправка и конфликты.
- `application-state`: сохранение состояния, жизненный цикл окна и приложения, восстановление и управление ресурсами.
- `executor-settings`: обнаружение CLI, штатный подписочный вход, модели, разрешения и наследование конфигурации.
- `desktop-delivery`: локальная сборка для macOS со встроенным Node.js и сохранение данных при ручном обновлении.

### Modified Capabilities

Отсутствуют: существующих спецификаций в проекте нет.

## Impact

- Изменение создаёт первое приложение; исходного кода, тестов и сборочной конфигурации сейчас нет.
- Основные зависимости: Tauri 2, React, SQLite, CodeMirror 6, xterm.js, portable-pty, установленный Git, Codex app-server и Claude Agent SDK.
- Интерфейсы подключения сверены с исходниками Orca. Первый этап фиксирует реальные проверки Codex и, по уточнению пользователя о недоступном локальном Claude, локальные проверки его SDK по флоу Orca. Реальная совместимость Claude и применимость условий распространения остаются отдельными неподтверждёнными пунктами до приёмки готового приложения.
