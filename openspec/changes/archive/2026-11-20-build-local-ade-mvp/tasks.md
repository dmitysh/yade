# Tasks

Порядок сохраняет зависимости: этап 1 подтверждает обязательные подключения до основной работы над интерфейсом. При отрицательном результате сначала пересматривается подключение и обновляются артефакты; подписки не заменяются API-ключами.

Уточнение пользователя от 10 ноября 2026 года: локальный Claude Code не работает; его реальная подписочная проверка на этой машине недоступна. Для первого этапа реализуется флоу Orca с проверками на границе SDK и сверкой исходников. Это позволяет продолжать реализацию без повторного входа здесь. Реальная совместимость Claude и условия распространения остаются явно неподтверждёнными; локальные тесты не подменяют проверку перед приёмкой готового приложения.
