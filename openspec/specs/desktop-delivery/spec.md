# desktop-delivery Specification

## Purpose

Готовое локальное приложение для macOS с необходимой средой выполнения и сохранением пользовательских данных при ручной установке новой версии.

## Requirements

### Requirement: Локальное приложение macOS

Первый выпуск ДОЛЖЕН (SHALL) предоставлять готовое устанавливаемое приложение для macOS, работающее с локальными проектами и состоянием пользователя без отдельного сервера ADE.

#### Scenario: Запуск готовой сборки
- **WHEN** пользователь устанавливает и открывает приложение на поддерживаемой macOS
- **THEN** доступен локальный рабочий интерфейс и сохранение состояния
- **AND** для работы приложения не требуется отдельный сервер ADE

### Requirement: Включённая среда выполнения

Приложение ДОЛЖНО (SHALL) включать Node.js и необходимые компоненты подключения Claude. Claude Code, Codex и Git остаются отдельно установленными инструментами пользователя; отсутствие любого из них должно объясняться.

#### Scenario: Без отдельного Node.js
- **WHEN** на компьютере нет отдельно установленного Node.js, но нужные CLI доступны
- **THEN** готовое приложение может запустить подключение Claude через включённую среду

#### Scenario: Отсутствует внешний инструмент
- **WHEN** готовая сборка не обнаружила Claude Code, Codex или Git
- **THEN** показано, какой инструмент требуется установить
- **AND** сбой не маскируется под успешный запуск

### Requirement: Ручное обновление с сохранением данных

Приложение ДОЛЖНО (SHALL) поддерживать ручную установку новой версии с сохранением локальных проектов, истории, черновиков и настроек. Ошибка обновления структуры данных не должна уничтожать исходное состояние.

#### Scenario: Успешное обновление
- **WHEN** пользователь устанавливает новую совместимую версию поверх предыдущей
- **THEN** сохранённые проекты, разговоры, черновики и настройки доступны после запуска

#### Scenario: Ошибка обновления данных
- **WHEN** изменение структуры сохранённых данных завершается ошибкой
- **THEN** исходные данные сохраняются, а пользователь видит причину
- **AND** приложение не запускается с ложным статусом успешного обновления
