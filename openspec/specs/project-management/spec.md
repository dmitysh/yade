# project-management Specification

## Purpose

Организация локальных исходников в проекты и группы, чтобы пользователь мог переключаться между задачами и сохранять независимость репозиториев.

## Requirements

### Requirement: Открытие локального проекта

Приложение ДОЛЖНО (SHALL) позволять открыть существующий локальный Git-репозиторий или обычную папку как проект и отображать его тип и расположение.

#### Scenario: Открытие репозитория
- **WHEN** пользователь выбирает существующий Git-репозиторий
- **THEN** создаётся доступный для работы проект, связанный с этим репозиторием

#### Scenario: Открытие обычной папки
- **WHEN** пользователь выбирает существующую папку без Git
- **THEN** папка открывается как проект без создания репозитория

#### Scenario: Недоступное расположение
- **WHEN** выбранная папка отсутствует или недоступна
- **THEN** показывается причина ошибки, а проект не помечается успешно открытым

### Requirement: Группировка независимых проектов

Приложение ДОЛЖНО (SHALL) позволять объединить отдельные проекты в именованную группу, в том числе связанную с общей родительской папкой, сохраняя их отдельные репозитории.

#### Scenario: Группа из нескольких репозиториев
- **WHEN** в группе находятся два проекта с разными репозиториями
- **THEN** оба проекта доступны в группе
- **AND** у каждого сохраняются собственные ветки, история и область Git-операций

#### Scenario: Общая родительская папка
- **WHEN** группа соответствует папке с несколькими проектами
- **THEN** можно работать с общей папкой группы без создания общей истории Git

### Requirement: Переключение проекта

Приложение ДОЛЖНО (SHALL) переключать видимый контекст между открытыми проектами и сохранять связь их пространств, сессий и вкладок.

#### Scenario: Переключение при активной работе
- **WHEN** пользователь переходит из проекта с выполняющейся сессией в другой проект
- **THEN** показывается контекст выбранного проекта, а первая сессия продолжает работу в исходном пространстве

#### Scenario: Возврат в проект
- **WHEN** пользователь возвращается в ранее открытый проект
- **THEN** доступны его ранее открытые пространства и представления
