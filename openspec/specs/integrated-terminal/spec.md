# integrated-terminal Specification

## Purpose

Запуск интерактивных системных оболочек в контексте рабочего пространства для команд разработки, тестов и локальных приложений.

## Requirements

### Requirement: Интерактивная оболочка пространства

Приложение ДОЛЖНО (SHALL) позволять открыть несколько интерактивных терминалов с начальной рабочей папкой выбранного пространства и передавать ввод и вывод соответствующей оболочке.

#### Scenario: Команда в пространстве
- **WHEN** пользователь открывает терминал и запускает команду
- **THEN** команда выполняется из папки выбранного пространства, а вывод отображается в этом терминале

#### Scenario: Два терминала
- **WHEN** пользователь открывает две оболочки и вводит команды
- **THEN** ввод и вывод каждого терминала остаются связаны с его процессом

### Requirement: Изменение размера и управляющий ввод

Приложение ДОЛЖНО (SHALL) передавать изменение размера терминала и управляющие клавиши запущенному терминальному процессу.

#### Scenario: Изменение панели
- **WHEN** пользователь меняет размер панели терминала
- **THEN** оболочка получает актуальный размер и вывод отображается в новой сетке

#### Scenario: Прерывание команды
- **WHEN** пользователь нажимает Ctrl+C в терминале с выполняющейся командой
- **THEN** управляющий ввод получает эта команда через её терминал
- **AND** другие терминалы и сессии не прерываются

### Requirement: Фактический результат терминального процесса

Приложение ДОЛЖНО (SHALL) показывать ошибку запуска или завершение оболочки и позволять явно завершить выбранный терминальный процесс без воздействия на чужие процессы.

#### Scenario: Ошибка запуска оболочки
- **WHEN** оболочка не может быть запущена
- **THEN** терминал показывает причину и не выглядит работающим

#### Scenario: Завершение терминала
- **WHEN** пользователь явно завершает выбранный терминальный процесс
- **THEN** завершается выбранный процесс и отражается его состояние
- **AND** остальные терминалы и сессии продолжают работу
