# executor-settings Specification

## Purpose

Использование установленных Claude Code и Codex со штатным подписочным входом, обнаружением несовместимости и наследованием пользовательской и проектной конфигурации.

## Requirements

### Requirement: Обнаружение установленных CLI

Приложение ДОЛЖНО (SHALL) обнаруживать установленные Claude Code и Codex, определять их версии и доступность штатного входа и объяснять отсутствие инструмента, входа либо ошибку проверки CLI. Номер версии CLI НЕ ДОЛЖЕН (SHALL NOT) ограничивать запуск.

#### Scenario: Оба исполнителя доступны
- **WHEN** оба CLI установлены и пользователь вошёл в них
- **THEN** доступно создание сессии каждого исполнителя

#### Scenario: Любая версия CLI
- **WHEN** установленный CLI сообщает произвольный номер версии и штатный вход доступен
- **THEN** номер версии показывается для диагностики и не блокирует создание сессии

#### Scenario: Инструмент не установлен
- **WHEN** один из CLI отсутствует
- **THEN** показано, какой инструмент нужно установить
- **AND** второй доступный исполнитель остаётся пригоден для работы

#### Scenario: Нужен вход или проверка CLI завершилась ошибкой
- **WHEN** CLI установлен, но штатный вход отсутствует либо проверка CLI завершилась ошибкой
- **THEN** показана конкретная причина и необходимое действие
- **AND** сессия не объявляется успешно запущенной

### Requirement: Личные подписки и штатный вход

Приложение ДОЛЖНО (SHALL) использовать личные подписки через существующий штатный вход установленного Codex и неизменённого Claude Code. Приложение не должно собирать или копировать токены, подменять штатную аутентификацию либо требовать API-ключ для этого сценария.

#### Scenario: Использование существующего входа
- **WHEN** пользователь уже вошёл в установленный CLI по поддерживаемой подписке
- **THEN** приложение использует этот вход без отдельного сбора учётных данных

#### Scenario: Подписка не позволяет продолжить
- **WHEN** исполнитель сообщает об ограничении подписки или необходимости входа
- **THEN** причина показана в соответствующей сессии
- **AND** приложение не переключает пользователя на API-ключ автоматически

### Requirement: Наследование привычной конфигурации

Приложение ДОЛЖНО (SHALL) запускать каждого исполнителя в контексте выбранного пространства со штатным пользовательским профилем. Проектные инструкции, навыки, MCP-серверы и настройки загружаются для доверенного пространства. Конфигурация одного исполнителя не должна подменять конфигурацию другого.

#### Scenario: Инструкции и MCP проекта
- **WHEN** доверенное пространство содержит применимые инструкции, навык и MCP-сервер выбранного исполнителя
- **THEN** встроенная сессия получает эти возможности так же, как штатный запуск в этом контексте

#### Scenario: Доверие при запуске разговора Claude
- **WHEN** пользователь отправляет сообщение Claude из пространства без подтверждения доверия
- **THEN** приложение запрашивает подтверждение для этого пространства и его пути
- **AND** отказ оставляет сообщение в редакторе и не запускает разговор
- **AND** каталог настроек и фоновый запрос названия запускаются вне пространства с отключёнными хуками и MCP из файлов

#### Scenario: Разные исполнители
- **WHEN** в пространстве используются Claude Code и Codex с разными настройками
- **THEN** каждая сессия использует конфигурацию своего исполнителя

### Requirement: Модель и разрешения

Приложение ДОЛЖНО (SHALL) показывать применимые модели и режимы разрешений выбранного исполнителя и передавать явно выбранные значения соответствующей сессии. При отсутствии переопределения сохраняется штатная конфигурация исполнителя.

#### Scenario: Явный выбор параметров
- **WHEN** пользователь выбирает поддерживаемую модель и режим разрешений
- **THEN** параметры применяются к выбранной сессии

#### Scenario: Параметр не поддерживается
- **WHEN** исполнитель отклоняет выбранную модель или режим
- **THEN** показана ошибка, а интерфейс не показывает неприменённый параметр как действующий

#### Scenario: Штатные настройки
- **WHEN** пользователь не задаёт переопределение
- **THEN** используются соответствующие штатные настройки исполнителя
